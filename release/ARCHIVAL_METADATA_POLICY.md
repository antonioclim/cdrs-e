# Archival metadata policy

`CITATION.cff` is the source metadata for repository and GitHub–Zenodo integration. This source snapshot contains no fabricated DOI, no guessed publication date and no local Zenodo operation plan.

If a real archival record later exists, its DOI belongs first in the external release or deposit metadata. Updating source metadata is a separate versioned change; the frozen release-candidate tag must not be rewritten merely to backfill a DOI.
