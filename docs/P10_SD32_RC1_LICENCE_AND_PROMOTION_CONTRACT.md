# P10-SD32 Apache-2.0 rc1 licence and promotion contract

`cdrs-e 0.1.0rc1` is a locally built and qualified release candidate derived
from the qualified `0.1.0.dev7` source tree. The authorised changes are limited
to release identity, Apache-2.0 licensing, citation/discovery metadata, release
status reporting and the regression tests needed to lock those boundaries.

The algorithmic, numerical, economic, certificate and verification modules are
required to remain byte-identical to dev7. Existing scientific thresholds, seeds
and numerical expectations are not weakened.

Apache-2.0 is selected and locally applied. This does not authorise repository
creation, push, tag, public release, Zenodo deposit, DOI creation, PyPI upload,
editorial upload, submission or costs. The intended future public route is
GitHub public plus Zenodo, subject to separate exact authorisation.
